## О проекте
## Основной фаил v13.py!
Проект хакатона ForteBank 2025 по детекции мошенничества в транзакциях.

Система строится на ансамбле моделей (LightGBM + XGBoost + CatBoost + meta-model на логистической регрессии) и большом количестве поведенческих фич по клиенту: история сумм, интервалы между транзакциями, дневной/ночной профиль, смена устройства/ОС, активность в сессиях и т.д.

Основное время ушло не на обучение моделей, а на оптимизацию признаков:
- часть фич давала красивый ROC-AUC, но ломала бизнес-метрики (перегоняла FP/FN не туда);
- некоторые “умные” признаки по факту вносили шум и вредили generalization;
- приходилось много раз пересобирать историю клиента и проверять, какие комбинации реально ловят фрод, а какие просто переобучаются.

## Текущие ограничения и планы

На момент первого коммита есть несколько известных проблем:

- Мало данных по редким паттернам поведения → модель нестабильна на “хвостах” распределения.
- Часть временных и поведенческих фич переобучена на текущий датасет, нужны проверки на более насыщенной выборке.
- Пороги, подобранные по текущим данным, могут сместиться при росте базы и изменении доли фрода.
- Холодный старт для новых клиентов/устройств пока решён простыми хардкод-правилами и усреднениями.

Ожидается, что по мере накопления реальных данных (более насыщенная история по клиентам, устройствам, типам мерчантов) часть этих проблем уйдёт:
- можно будет пересчитать все распределения и z-score-фичи,
- переобучить meta-model и пороги уже на стабилизированной статистике,
- отфильтровать “вредные” признаки, которые не переживают смену распределения.
